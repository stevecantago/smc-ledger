# Project Rules & Permissions

All permissions and access policies for this project are configured to full access.

## Access Policy
- **File Access**: Full access allowed (`AGENT_SETTING_POLICY_ALLOW`).
- **Command Execution**: Full access eager execution (`CASCADE_COMMANDS_AUTO_EXECUTION_EAGER`).
- **Sandbox Mode**: Disabled (`sandboxMode: false`).
- **Tool & MCP Access**: Full access (`*`).
